# 知衡 · 条件选股 Demo

把自然语言选股想法转成可修改的条件，用真实数据筛选上证 50，查看每只股票入选或排除的原因。

[打开 Demo](https://stock-intent-lab-zheng.liaoyanqing666.chatgpt.site) · [源码仓库](https://github.com/zhengxinyu31-byte/test)

面向同花顺场景中有基本财务知识、不会写选股表达式的个人投资者：读完财报或查看自选股后，想把“经营改善、估值合理、走势稳定”变成下一步研究名单。本项目是独立 Web 原型，没有接入同花顺账户或交易系统。

## 使用

1. 输入想法，点击“解析条件”。
2. 确认指标、阈值和财报期。“估值合理”不会自动填入统一 PE；需自己输入上限，或明确选择本次不筛估值。
3. 执行筛选，查看“符合条件 / 未通过 / 无法判断”。点击股票打开原始字段、计算过程和请求标识。
4. 修改条件并再次执行，查看同一数据快照下新增、移出的股票。
5. 最多比较三只股票；保存条件和本次结果，刷新页面后可从“已保存”恢复。

保存仅使用当前浏览器 localStorage，最多 5 条。重新打开的是历史结果；再次执行才获取当前数据。修改后的草稿未执行时，保存仍保存上次结果。

## 本地启动

需要 Node.js 22.13+（开发使用 24.15）、npm，以及扶摇和 OpenRouter 的独立凭据。

```bash
npm ci
cp .env.example .dev.vars
# 在 .dev.vars 中填入自己的凭据
npm run dev
```

打开终端显示的地址，默认 `http://localhost:5173`。缺少模型凭据时可手动设置条件；缺少数据凭据时会显示错误，不提供伪造股票数据。

```bash
npm test
npm run typecheck
npm run build
```

浏览器验证需要 Chrome 或 Playwright Chromium：

```bash
CHROME_PATH="/path/to/chrome" npm run test:browser
CHROME_PATH="/path/to/chrome" npm run test:faults
```

默认 Chrome 路径为 macOS 标准安装位置。浏览器主链路测试会访问真实金融和模型接口；故障测试用明确标注的模拟响应。真实模型评测：

```bash
node --experimental-strip-types scripts/evaluate-model.mjs outputs/model-evaluation.json
```

运行产物位于 `outputs/`，已加入忽略规则，不能提交供应商原始数据或个人记录。

## 环境变量

| 变量 | 用途 |
| --- | --- |
| `FUYAO_API_KEY` | 扶摇 REST 数据，服务端使用 |
| `OPENROUTER_API_KEY` | 服务端意图解析 |
| `LLM_MODEL` | 默认 `dots-studio/dots-3-note-preview:free`，可替换；记录实际返回模型 |

免费模型会限流、超时，也可能返回语义错误。不会把规则解析伪装成模型成功；错误时可重试或手动编辑。默认模型是根据真实对照测试选择的，不能保证未来可用。

## 技术与数据

React 19、TypeScript、Vinext，部署到 Cloudflare Workers。Sites 管理源码版本、生产环境变量和部署。保留了 Sites 提供的构建文件，应用逻辑位于 `components/stock`、`lib/stock`、`app/api`。

- **AI**：生成条件、澄清和有限修改。只接收选股表达、指标定义和当前条件；不生成股票数据，不负责入选判定。
- **确定性引擎**：验证字段、比较符和互斥区间；按未四舍五入值筛选，计算变化和解释证据。
- **数据适配**：扶摇获取当前上证 50、财报原值、估值、交易日历与前复权日收盘价。缺失、异常和调用失败分别记录。
- **界面**：展示已执行条件及数据，草稿和历史状态分开；保留用户主动略过的要求。

`POST /api/interpret` 接收 `{query,report,conditions,mode,revision}`；返回条件、澄清、不支持项、未解决事项和模型标识。修改模式只接受有限补丁。

`GET /api/dataset?report=2026H1` 返回带版本的数据；可选 `2025FY`，`refresh=1` 请求刷新。服务端短时缓存 15 分钟，主动刷新最短间隔 1 分钟。金融请求并发数 2，单次 12 秒超时，限流最多重试一次。入口有按 IP 的进程内限流；多实例严格配额需另接网关或持久化限流，当前不是生产级抗滥用方案。

| 指标 | 口径 |
| --- | --- |
| 营收 / 归母利润同比 | 2026 中报或 2025 年报累计值对比上年同期；基期为正；使用利润表原值计算 |
| PE(TTM) | 最新可取得估值快照的正倍数；元数据时间不保证每个字段同步 |
| 60 日年化波动率 | 61 个完整交易日价格，60 个对数收益，样本标准差 × √252 × 100% |
| 60 日最大回撤 | 同窗口内，收盘价相对此前最高收盘价的最大跌幅，按正百分数展示 |

各项证据保留来源、字段、原值、单位、期间、来源与获取时间、公式和请求追踪 ID。金融数据以实际可调用接口为准：[扶摇文档](https://fuyao.aicubes.cn/docs/)。

iFinD Skill 已另行安装并完成真实行业分类查询。响应只有“最新”时间口径，因此没有把它接成可复算的行业相对估值引擎；Demo 运行不依赖 iFinD。它的凭据独立于扶摇，也不进入仓库。

## 产品边界

- 仅当前上证 50、AND、最多 8 项条件、两个固定报告期。
- 银行、周期、成熟盈利、亏损成长企业的指标适用性不同；不提供通用“合理 PE”，不自动生成行业标准。
- 不支持行业筛选 / 相对估值、PB、ROE、任意价格窗口、新闻条件、OR。用户要明确处理不支持项后才执行。
- “增长为正”不等于增速加快；低波动不等于低回撤；未查现金流不等于现金流异常。
- 不做买卖建议、确定性涨跌预测、收益承诺、下单、自动监控或回测。当前成分与修订财报不能冒充历史时点数据。
- 自然语言理解无法由有限规则完全证明；模型输出始终需要用户确认。已知测试范围和失败见验证记录。
