# 知衡 · 按想法选股

输入一句选股想法，直接查看真实数据的初筛结果和采用的条件。支持改条件、查看新增与移出、比较三只股票和保存本次研究。

[打开 Web Demo](https://stock-intent-lab-zheng.liaoyanqing666.chatgpt.site) · [源代码](https://github.com/zhengxinyu31-byte/test) · [题目验收对照](docs/REQUIREMENTS-CHECKLIST.md)

这是同花顺行业研究场景的独立交互 Demo，没有接入同花顺账户、持仓或交易系统。目标用户已关注某个行业，但不熟悉选股公式。当前切口是白电整机观察组：同花顺白色家电板块，剔除家电零部件板块成员。名单由扶摇获取，不冒充申万分类；组内公司业务仍有差异。

## 怎么用

1. 输入想法或点选六个示例之一，点击“按这个想法筛选”。首次不用填写指标或勾选确认。
2. 查看本次采用的条件和解释。实质歧义会澄清；不支持的要求会保留并阻止执行，不会偷偷省略。
3. 在“符合条件 / 未通过 / 无法判断 / 默认方案不适用”中查看完整名单，点击“看依据”核查原值、公式、时点和来源。
4. 尝试调整，先看新增、移出和状态变化，再应用或撤销。也可修改具体阈值。
5. 最多比较三只；一键保存条件、原始想法及本次结果。历史结果明确标记，不当成当前行情。

六个问句包括：经营改善与相对估值、利润增长与明确PE上限、历史起伏和回落、本期盈利与均线位置、扭亏、明确60日涨幅与营收同比。示例是研究后构造的表达，不声称是客户日志。

## 本地启动

需要 Node.js >=22.13（验证使用24.15）、npm，以及扶摇/OpenRouter的独立凭据。

```bash
npm ci
cp .env.example .dev.vars
# 只在本机 .dev.vars 填入自己的凭据
npm run dev
```

打开终端显示的地址，默认 `http://127.0.0.1:5173`。金融数据失败时显示错误，不用构造股票补结果。模型失败时可主动使用页面上的已核对示例，明确标记“未调用模型”。

```bash
npm test
npm run typecheck
npm run build
```

真实浏览器验收（需要 Chrome；可用 `CHROME_PATH` 指定可执行文件）：

```bash
npm run test:browser
npm run test:faults
node --experimental-strip-types scripts/evaluate-v5.mjs outputs/my-model-eval.json
```

浏览器验证使用真实接口，故障注入部分明确标记为测试。`outputs/`只存本机测试产物和供应商数据，已忽略，不得提交。旧版浏览器脚本保留作历史记录，v5主链路使用 `scripts/browser-v5.mjs`。

## 环境变量

| 变量 | 用途 |
|---|---|
| `FUYAO_API_KEY` | 扶摇REST真实金融数据，只在服务端使用 |
| `OPENROUTER_API_KEY` | 运行时模糊意图解析，只在服务端使用 |
| `LLM_MODEL` | 默认 `dots-studio/dots-3-note-preview:free`，记录实际返回模型，可自行替换 |

不把模型调用成功率当作理解准确率。免费模型会限流、超时或输出不完整；系统不会把这些情况伪装成正常结果。纯数字条件可由程序直接解析，并如实标明没有调用模型。

## 职责边界

| 模块 | 负责 | 不负责 |
|---|---|---|
| 问句知识库 | 19类目标、专业定义、适用范围、边界与出处；11类当前可执行 | 不证明策略收益，不使用未经验证的社区数字 |
| AI | 从表达识别目标、明确约束和待澄清事项 | 不编股票、金融数值、默认阈值或投资结论 |
| 确定性政策和引擎 | 计算分位数默认值、校验冲突、逐股执行、生成变化 | 不运行模型SQL或代码，不合成买入分数 |
| 金融数据适配 | 获取、校验、标准化和留证 | 不补零、不补价格、不把失败当成功 |
| 界面 | 用平实说明展示事实、默认解释与局限 | 不把历史低波动称为未来安全 |

## 数据与默认条件

扶摇提供当前成分股、估值、利润表、交易日历和前复权日价格。`/api/screen`将意图编译和数据获取串联；`/api/screen/change`仅修改已有基础条件。旧 `/api/interpret` 与 `/api/dataset` 保留兼容，但不再驱动首屏。

- **经营改善**：营收与归母净利润同比均>0。固定报告期为2026年中报，或用户明确的2025年报；正增长不等于增长加速。
- **估值别太高**：正PE(TTM)不高于本组适用公司的中位数。默认比较要求近两年、本期及同比基期归母利润均为正。只作组内参考，不给公允价值。
- **走势稳定**：60日年化波动率和最大回撤各不高于对应组内中位数。价格基准不附加盈利门槛，不能外推未来损失。
- **盈利/扭亏**：直接检查归母利润原值的正负；负基数不计算常规增长率。
- **价格趋势**：完整窗口计算20日均线位置、60日价格涨幅；不当作上穿事件或策略回测收益。

相对参考线须至少5个有效样本、覆盖率至少80%，为产品试行门槛。样本不足时无法判断。基准先于筛选计算，同一次调整固定数据和基准；刷新另起一次，明确数值保留，相对条件按新数据重算。

数据缓存15分钟，主动刷新最短间隔1分钟；最多两条上游请求并发，单次12秒超时，限流重试一次。公开接口限制输入和进程内IP频率；不是分布式生产防滥用系统。

[扶摇文档](https://fuyao.aicubes.cn/docs/)是数据接口来源。iFinD Skill 1.5.0已独立安装，并完成行业查询；部分响应只给数量或“最新”口径，未用它冒充可复算的比较组。Demo运行不依赖iFinD，凭据不与扶摇复用。

## 边界与未做

只执行命名观察组中的AND条件，不覆盖全A。分红、现金流、ROE/质量、多期加速、公告超预期、盘中突破和银行/周期专用估值进入知识库，但当前明确不执行。不会用低PE代替高股息，或用利润增长代替现金流。

没有完整逐公司业务可比性审查，因此“本组中位数”不是行业合理价。数据来自当前接口版本，不声称历史时点可得，不做回测、自动监控或交易。保存最多5次，仅在当前浏览器；清除浏览器数据会丢失保存内容。

本项目经过多轮研究迭代，不能宣称整个交付从零只用了两小时。两小时作为MVP范围与演示提交约束。无演示视频，提供90秒操作脚本。
