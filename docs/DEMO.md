# 两分钟演示脚本

0–20 秒：输入“经营改善、估值合理、走势相对稳定”，点击“解析条件”。展示原话对应的营收、归母利润和历史波动条件。说明：AI 只解析，尚未筛选股票。

20–40 秒：在估值澄清中自行输入 25 倍作为这次演示的 PE 上限。它是演示者选的条件，不是行业合理估值。展开波动率说明，指出持续小幅下跌也可能低波动，用户可以改看最大回撤。

40–70 秒：确认后筛选上证 50。切换符合、未通过和无法判断；打开一只股票，展开原始财报字段、统计期间、计算式和请求标识。数字来自实际接口，演示时不预报入选数量。

70–95 秒：把 PE 上限改为 15，页面提示下方仍为上次结果。再次确认并执行，查看同一数据下新增、移出和状态变化。若无变化，就说明实际结果没有变化。

95–120 秒：选三只股票并排查看指标，保存方案；刷新页面，从“已保存”打开。指出这是带日期的历史结果，重新筛选才获取当前数据。

模型调用失败时：展示错误提示，使用“手动设置”继续；明确这一段没有完成模型解析，不把它说成 AI 成功。数据失败时展示错误，不用预制股票表代替。
