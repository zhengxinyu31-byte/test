# 90秒演示脚本

这是操作脚本，不是已制作的视频。结果数量会随真实快照变化，不照读固定股票数。

- 0–15秒：说明目标用户刚看完行业财报，想缩小下一步研究范围。指出页面已经带入“白电整机观察组”，没有账户或风险画像问卷。
- 15–35秒：点击“只看利润增长”示例，再点“按这个想法筛选”。指出只采用利润增长与用户明确的PE上限，不额外加波动条件。免费模型失败时如实展示失败，再主动点“使用当前示例方案”，说明来源不同。
- 35–55秒：打开一只股票“看依据”，展示实际值、条件、报告期、原始字段、公式与请求标识。切到“未通过”说明一项失败即排除，但缺失项仍展示。
- 55–75秒：查看条件并调整PE上限，先看新增、移出和状态变化，再应用；演示撤销。数据快照保持不变。
- 75–90秒：选两到三只比较，一键保存。打开“问法与口径”，说明“不要亏损”“扭亏”“均线上方”分别采用不同方法；高股息和现金流目前明确不执行。

可扩展到120秒：输入“稳健”展示选择式澄清；输入“PE大于30，PE小于20”展示冲突；再输入“银行股便宜”说明范围边界。
