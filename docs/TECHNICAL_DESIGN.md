# 自然语言选股技术设计 v5

当前交互与v4不同：常规流程先给初筛结果和解释，不要求用户逐个填写阈值。旧版契约与测试保留；v5主入口为 `POST /api/screen`。

## 1. 编译与执行

输入 → 边界/明确数字检查 → 必要时调用模型识别目标 → 原话、字段和数值校验 → 取真实快照 → 确定性政策解析 → 逐股执行 → 展示解释 → 同快照调整。

`knowledge.ts`是策略定义、模型提示、界面说明和测试的共同来源。19类意图中11类可执行；没有向量检索、任意SQL、代码执行或Agent自主循环。纯数字条件直接解析；模糊表达一次模型调用，45秒超时，无后台循环尝试生成“好结果”。

| 文件 | 关键接口及责任 |
|---|---|
| screen-intent.ts | preflightIntent、explicitNumbers、validatePlan、compileIntent；目标与显式约束 |
| screen-policy.ts | buildBenchmarks、resolvePlan、evaluateScreen、difference、changeConditions、rebaseConditions |
| peer-data.ts | 成员集合差、同口径盈利历史原值与有效性 |
| data.ts | 并发、超时、缓存、供应商契约、财报及价格证据 |
| screen-storage.ts | 本地保存恢复校验与重新计算，不信任损坏嵌套对象 |
| screen-details.tsx | 单层证据/知识库/范围说明 |
| workbench.tsx | 输入、结果、条件解释、修改预览、比较保存 |

模型不接收密钥、持仓或全量金融原值，只接收问句、有限当前条件及指标定义。生成的金融结论不进入展示；实际数值、比较和来源来自程序。

## 2. 契约

`IntentPlan`保存query、goals、constraints、unsupported、question、report、model/requestId、knowledgeVersion。`ScreenCondition`保存field/op/value、sourceText、origin（user/default/edited）、goal、basis、benchmark/percentile和profitGate。null阈值表示基准不可用，不意味着0。

`ScreenRun`保存plan、dataset、benchmarks、conditions、evaluations、executedAt和history。Dataset具有唯一版本和独立各项时点；不宣称所有字段同步更新。每项Evidence包含source、endpoint、field、requestId、原值、单位说明、期间、来源时间、获取时间与计算公式。

## 3. 财务与价格计算

累计收入、累计归母净利润按同一期末和上年同期计算 `(本期-基期)/基期*100%`。币种CNY，披露日期不得晚于获取时间，基期必须为正；扭亏另查两期符号，不复用同比。默认PE适用性核对2024/2025年报与2025/2026中报；选择2025年报则只核对两年年报。

风险指标使用61个完整前复权收盘价、60个对数收益。波动率为样本标准差(ddof=1)×sqrt(252)×100%；回撤为最大历史峰谷跌幅正百分数。任意缺失/重复交易日、非正价格、无成交均不能补值。20日均线含窗口末日；60日涨幅是价格变化，不是总收益。

## 4. 两种比较组

U=当前881131.TI成员减884116.TI成员。完整保存两次名单的来源与请求标识，拒绝重复或非子集异常。不将集合差称为经过商业模式调整的可比企业组。

PE组排除已知不适用的非正盈利历史，未知适用性留在覆盖率分母；有效PE除以已确认适用+待定数。价格组不看盈利，分母为U全体。各项有效样本≥5且覆盖率≥80%，才线性插值P25/P50/P75；这些是可审查的产品政策，不是假称金融业统一标准。

基准在执行前固定。放宽、收紧、编辑均不重新选择比较组。刷新保留显式数值，重新解析相对参考线，并创建新运行。

## 5. 判断语义

四类互斥：任一确定失败→未通过；无失败但默认PE适用门槛已知不符→默认方案不适用；无前两类但数据或基准未知→无法判断；全部通过→符合。即使已有确定失败，其余未知/不适用项仍在逐项依据中保留。四类总和等于完整U。

比较使用未舍入数值。UI只格式化显示，临界情况可查看原值与阈值。严格条件可返回0；互斥条件阻止执行。移除单项的预览展示真实重算数量，不自动修改。

## 6. 修改与状态

明确的数字修改用严格整句匹配直接解析，实际标明未调用模型；其余自然语言修改使用受限模型补丁，仅针对已有基础字段。其余条件及元数据必须保持。用户确认前仅预览；应用可撤销。修改与数据刷新分别记录；页面输入版本防止过期异步结果覆盖新输入。初筛原话和修改历史并存，不把编辑后的默认值说成用户原先要求。

保存本地最多5次，自动命名。恢复验证嵌套形状并从所存数据重新计算，明确历史状态。不能从“旧数据读取成功”推导“当前数据正常”。

## 7. 失败、安全与成本

扶摇HTTP失败、业务错误、鉴权、429、超时、空数组、字段缺失、异常日期均显式处理。部分失败保留完整股票池；全无可验证指标拒绝正常结果。缓存失败回退到重新取数；Cloudflare使用具名缓存，避免Workers for Platforms中caches.default不可用。

模型非法JSON、未知字段、编造数值、错单位/方向或不支持目标不放行。输入长度受限、按IP进程内限流；生产多实例防滥用仍需持久化限流。密钥仅服务端环境变量，输出/原始数据和参考材料不进源码库。免费模型是演示依赖，不承诺持续可用。
