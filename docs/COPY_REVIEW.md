# 界面文案修改记录

用户要求：贴合同花顺选股场景，简洁、清晰、有具体信息。已搜索、检查并安装 [Humanizer Chinese](https://github.com/jiji262/humanizer-chinese)，固定版本 `1d6c08e10fbfe0e1b36ac784834451c6aae0a92c`，本机目录 `~/.codex/skills/humanizer-chinese`。安装不执行其附带脚本。采用其中的文体适配、删除口号和空泛解释、保留事实规则；不使用检测分数证明“像人写的”，不编造经历或增加荐股措辞。

参考同花顺已有工具中的“条件选股、选股条件、保存方案、选择结果”等任务词汇：[官方功能说明](https://www.10jqka.com.cn/ad_mar/man/08-2.htm)、[iFinD 使用手册](https://zjcmpp.hexin.com.cn/download/jgb/iFinD_Manual.pdf)。这些较早的材料用于术语参考，不声称复刻当前 App 界面。

| 原文 | 修改后 | 理由 |
| --- | --- | --- |
| 让每一个选股想法，都有据可查 | 输入想法，按条件选股 | 直接说明功能 |
| 看结果，也看理由 | 筛选结果 | 去掉口号 |
| 不是一张“推荐名单”，而是一份可核对的研究结果 | 确认条件后查看结果 | 空状态告诉用户下一步 |
| 生成条件草稿 | 解析条件 | 缩短操作名称 |
| 保存研究 | 保存方案 | 使用工具场景中的常用词 |
| 我确认这些条件符合本次研究意图，阈值不是通用估值或安全标准 | 已核对指标、阈值和统计口径 | 确认项只描述确认动作；估值与风险限制单独保留 |
| “估值合理”的标准还未确定 | 估值按什么标准筛？ | 直接指出需要补充的内容 |

检查范围：首屏、条件卡、澄清、结果表、证据、比较、保存、历史状态、错误与空状态；模型提示词也加入短句要求。来源、时点、单位、不支持项、数据缺失和行业适用性未因精简而删除。
