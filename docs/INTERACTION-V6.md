# 当前交互：先解读指标，再选股

2026-10-15。用户要求回到三步主链路，本次只调整交互顺序，沿用已有真实数据、金融口径和确定性引擎。

1. **输入自然语言。** 首屏保留一个输入框、示例和“解读选股想法”。用户不必先填财务参数。
2. **看指标解读。** 将原话对应到金融指标，逐项展示名称、白话含义、本次条件和默认值依据。例如“经营改善”对应营业收入同比与归母净利润同比；解释同比大于0意味着什么。相对估值显示实际倍数、组内参考线及盈利门槛。必要歧义先澄清，冲突或未支持要求阻止继续。可按需调整条件，此时没有股票名单、命中数量或入选判断。
3. **点击选股。** 用户点击“按这些条件选股”后，程序执行已经展示的条件，展示候选与排除依据。比较、保存、修改后预览仍可用。

修改原话会清空旧解读及旧结果；返回后保留原文方便改写。查看历史保存结果仍明确标记历史，不能冒充新筛选。

## 数据与执行

相对阈值依赖真实组内分位数，因此解读阶段可以查询财务、估值、价格与名单，用于展示确切标准。查询数据不等于已经筛选：`prepareScreen`返回的数据不包含evaluations，`executePreparedScreen`才执行逐股判断。用户点击选股时不再调用模型或刷新数据，避免解释与实际执行不一致。

PreparedScreen只保存plan、dataset、benchmarks、conditions。选股前的手动修改标为edited；原始意图仍保留。API新增prepareOnly分支，旧接口行为保留兼容，不新增密钥或依赖。
