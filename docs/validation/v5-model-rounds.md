# v5 意图解析调试记录

这些问句来自研究后构造的回归集，不是独立保留集或真实客户流量。不能用通过率宣传AI准确率。

1. 首轮六个示例：5项符合编译预期。模型把明确PE附带为冗余模糊目标，原话校验拒绝；仅在显式约束已完整覆盖同一目标时消除冗余，不放过无关目标。
2. 第二轮扩展11场景：记录中8个pass标志，包含一次模型不完整、纯PE多问报告期，以及冲突用例的成功判据不正确。冲突场景应保留两约束，再由引擎拦截，不能要求它成为普通可执行方案。
3. 纯数字条件改为确定性解析，标明未调用模型。对任意模糊输入不使用规则伪装模型；失败可以手动编辑或主动采用已核对示例。
4. 最终修正后11场景符合预期。独立审查修复后重新实测，仍11项符合预期：6项真实模型调用、3项明确数字规则解析、2项前置边界。逐项输入、预期、实际、耗时、实际模型及请求标识见[v5-model-final.json](v5-model-final.json)。冲突实际阻止执行另有浏览器记录。
5. 自然语言局部修改另行实测；首次免费模型返回不完整，系统未修改条件。重试与原失败一同保存在[v5-change-real-model.json](v5-change-real-model.json)，不把一次重试成功解释为稳定性证明。
