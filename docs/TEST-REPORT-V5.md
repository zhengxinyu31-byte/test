## 对抗性审查与修复

最终变更由一名新上下文审查代理只读审查。发现6项重要问题，均先写失败复现，再修复；最后全套99/99通过。没有遗留的轻微审查项，也没有用第二次审查代替回归测试。

| 发现 | 修复及回归 |
|---|---|
| 自然语言局部修改清除了未修改条件的默认与基准元数据 | 只合并实际变化项，其他对象保持；RED→GREEN |
| 金额阈值被误译为同比 | 金额与同比明确区分，拒绝不支持的财务绝对额；RED→GREEN |
| 未支持的资产、报告期条件可能被省略 | 逐分句检查覆盖，不完整解释阻止执行；RED→GREEN |
| 模糊否定可能变成肯定目标 | 支持已核对的否定表达，其余明确拒绝；RED→GREEN |
| 快捷“放宽”可能收紧或误改同字段多区间 | 仅对合法默认相对上限提供单调操作；RED→GREEN |
| 预览只遍历旧条件，遗漏新增项 | 按新旧ID并集显示增加、删除与适用门槛变化；RED→GREEN |

补充回归遍历知识库全部已支持别名，避免新增边界检查误拦正常问法。已知复杂语言仍可能被拒绝；宁可说明未理解，也不展示被删掉条件的完整命中结果。
