# 从实际问法到可执行条件

检索日期：2026-10-15。研究方法为公开资料桌面研究，未接触同花顺后台日志，未做真实用户访谈。知识库实现位于 `lib/stock/knowledge.ts`，当前19类意图、11类可执行映射。策略类别数不等于独立投资策略，也不代表回测有效。

| 公开材料 | 观察到的表达/行为（转述） | 能说明什么，不能说明什么 |

## 2. 专业映射的取舍

[CFA 倍数估值教材](https://www.cfainstitute.org/insights/professional-learning/refresher-readings/2026/market-based-valuation-price-enterprise-value-multiples)要求理解盈利口径和周期性。周期盈利高点会压低PE，不能把低倍数直接解释为低估。[Damodaran 的相对估值讲义](https://pages.stern.nyu.edu/~adamodar/pdfiles/eqnotes/relintro.pdf)进一步说明：同一行业并不意味着增长、风险、现金流可比。因此页面采用“本组参考线”，不称“合理估值”。白电名单来自板块集合差，仍可能有多元业务公司；本版只作透明的组内数值比较，不给出经过业务调整的公允估值。

[MSCI 的质量与高股息定义](https://www.msci.com/indexes/factor-indexes/quality-and-high-dividend-yield-indexes)分别考虑盈利能力、稳定性、杠杆，以及分红持续性与支付能力。由此否定两种偷换：把“赚钱能力强”直接变成利润同比>0，把“高分红”变成低PE。此类要求进入知识库，但在缺少验证数据时阻止执行，并说明缺少什么。

[Fidelity 的均线定义](https://www.fidelity.com/learning-center/trading-investing/technical-analysis/technical-indicator-guide/sma)支持价格均值计算；[价格变化率定义](https://www.fidelity.com/learning-center/trading-investing/technical-analysis/technical-indicator-guide/roc)支持指定期间历史涨幅。Demo 可以利用同一真实价格窗口计算20日均线位置和60日涨幅。不能由“价格在均线上方”推出“当天上穿”或“接下来上涨”，也不把60日涨幅称为完整动量因子或策略回测。

## 3. 映射知识库的结构

每条包含：稳定ID、常见表达、要验证的事实、默认可执行解释、适用对象、不能推出的结论、出处、当前支持状态。运行时把可执行条目的定义交给模型；服务端只接受白名单ID和用户明确数字。指标默认值由程序计算，解释文案从知识库读取，金融数值来自数据引擎。

| 输入族 | 对应方法 | 当前处理 |
|---|---|---|
| 经营改善/营收增加/利润更多 | 同报告期财务比较 | 分别映射，不能统一加三套默认条件 |
| 便宜/估值别太高 | 正盈利观察组相对PE | 中位数起步，门槛和比较组公开 |
| 不大起大落/回落少/走势稳定 | 波动率、最大回撤或两者 | 按词义分别处理，默认窗口显式展示 |
| 不要亏损/本期盈利 | 本期归母净利润符号 | 不偷加同比增长 |
| 扭亏 | 两期原值符号比较 | 不以负基数算同比 |
| 收盘在20日均线上方 | 价格与SMA20比较 | 不当成突破或买点 |
| 近60日涨幅为正 | 历史价格变化 | 不称收益预测 |
| 明确PE、同比、波动、回撤或涨幅数字 | 用户约束 | 保留比较符、单位、时期；先验冲突阻止执行 |
| 分红、现金流、质量、加速、超预期、盘口 | 各自专用定义 | 知识库识别并解释数据缺口，不降格替换 |
| 银行、煤炭等其他范围 | 专用股票池与财务框架 | 范围外不能默认为白电；提示当前可用范围 |
| 便宜或者稳、模糊“稳健” | 逻辑或/目标歧义 | 不转AND；实质歧义用短选项澄清 |
| 必涨、保本、直接买什么 | 不可验证预测/交易建议 | 保留合法筛选部分需用户明确，不能承诺结果 |

## 4. Agent 设计与评测方法

采用“受限语义解析 → 确定性政策 → 验证 → 执行”，无需多Agent、向量库或自由工具规划。[PICARD](https://aclanthology.org/2021.emnlp-main.779/)是结构约束的研究参考；本项目并未复现其解码算法，也不能把JSON合法率称作意图理解准确率。

评测拆为：目标识别、范围/时间/否定/单位保留、显式阈值保留、默认仅作用于提到的目标、冲突保留、不支持项不丢失，以及事实与解释一致。构造问句与来源样本分开记录，防止把提示词中的固定例子当泛化能力。真实模型失败和拒绝执行也纳入记录。

## 5. 对抗性审查结论

1. 只用题干问句会让界面退化成固定模板：本版以六个不同目标组合验收，纯PE、仅走势、盈利状态不得夹带经营增长。
2. 让用户填写所有阈值没有解决需求：默认选P50及增长分界，结果旁说明原因；只在语义冲突或未知目标时问问题。
3. 扩充意图库不等于上线所有策略：缺少数据就说明限制，不生成假按钮和假候选。
4. 自动默认有锚定效应：标注“本次默认”，可查看、改数值、预览变化、撤销，不写“最佳”或“推荐”。
5. 分位数会随筛选结果改变导致循环解释：先在完整命名组算基准，后续调整冻结基准；刷新单独记录。
6. 窄行业也不能保证完全可比：披露组定义与名单，不声称业务可比性已逐一审核；不给公允价值结论。
7. 支持多问法不能静默丢条件：任何未执行要求阻止完整筛选；提供可执行的示例是用户主动替换，原输入保留在页面。
