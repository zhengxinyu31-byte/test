# 测试说明

测试使用预先定义的数学结果、结构与业务规则，不用模型自评证明正确。真实接口验证与故障注入分开。测试样例由 AI 草拟并在开发中修正，未经过独立金融专家标注，也不是用户研究。

## 可复跑检查

- `npm test`：确定性计算、适配、语义校验、保存恢复和审查回归。
- `npm run typecheck`：TypeScript 检查。
- `npm run build`：生产构建。
- `npm run test:browser`：真实模型和数据的浏览器主链路，需要配置密钥及 Chrome。
- `npm run test:faults`：独立浏览器上下文注入模型失败和数据失败。
- `node scripts/browser-regressions.mjs`：后续修改不得清除未解决要求。
- `node scripts/verify-secrets.mjs`：检查提交候选文件、前端产物及 Git 历史是否含本机实际密钥。仅输出文件名和数量。

## 浏览器检查

真实链路：模糊表达 → PE澄清并自行设值 → 50股筛选 → 入选及排除证据 → 改阈值 → 同快照变化 → 最多三股比较 → 保存 → 刷新恢复历史。另检验390px窄屏无页面横向溢出。

故障注入：模型503后可手动设置；数据502时没有正常结果。它们验证界面处理，不代表供应商曾发生相同故障。浏览器控制使用本机独立 Chrome；本会话内置浏览器连接不可用。

开发中曾发现测试按钮定位器漏掉空格，以及页面重载后在 hydration 完成前点击；修正测试等待与定位后重跑。没有把这些测试脚本错误当作供应商问题。

## 未覆盖与已知限制

没有独立市场数据对账、正式无障碍审计、大规模并发压测、长期免费配额可用性验证。429重试逻辑有限次，不保证上游服务可用。进程内限流不能替代分布式配额控制。没有测试不存在的回测、监控和交易功能。

## 公开环境发现的问题

首次匿名浏览器检查遇到模型输出不完整，页面提示重试或手动编辑。第二次解析成功，但数据接口报默认缓存不可访问。已复现：Cloudflare namespaced Worker 禁用 `caches.default`。改为具名隔离缓存，缓存不可用时仍获取真实数据；缓存写入失败不丢弃已验证的新数据。三个回归用例均先失败后通过，完整测试为 73/73。金融接口失败仍按原逻辑报告，不用旧数据填补。

平台依据：[Cloudflare Workers for Platforms 限制](https://developers.cloudflare.com/cloudflare-for-platforms/workers-for-platforms/reference/limits/)。这属于生产环境适配问题，不归因于金融供应商。

修复后，在[公开 Demo](https://stock-intent-lab-zheng.liaoyanqing666.chatgpt.site) 的独立匿名浏览器上下文中完成 10/10 项检查，无未捕获页面错误。前两次失败与最终成功均保留在 [公开验证记录](validation/public-browser.json)，不只展示成功样例。最后一次包含真实 AI、真实上证 50 数据、证据查看、条件变化、三股比较、保存恢复、窄屏和明确标注的故障注入。
